# Modelo de automação de testes - Desafio Técnico BRIDGE

## Pré-requisitos

* Python 3.x instalado.
* Git instalado.

## Passo a Passo

Como este repositório ignora arquivos de configuração sensíveis e ambientes virtuais, você precisará configurá-los manualmente na primeira execução.

### 1. Clonar o Repositório


### 2. Criar o ambiente virtual

No Windows
python -m venv venv

Ativar o ambiente
.\venv\Scripts\activate


### 3. Instalar as dependencias
pip install -r requirements.txt

### 4. Inserir seus dados de acesso no .env

Na raiz do projeto, faça uma cópia do arquivo .env.example e renomeie a cópia para .env.

Abra o arquivo .env recém-criado.

Preencha as variáveis *USER* e *PASSWORD* com as suas credenciais.
